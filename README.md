## 📖 Introduction
**EktaSahyog** is a next-generation Unity & Collaboration platform engineered at the intersection of the **MERN stack**, **WebGL-powered browser-native Web3D**, **AI-driven systems**, **OCR**, and **real-time infrastructure**.

We moved far beyond static MERN applications to architect a cultural-scale digital ecosystem — fusing multilingual AI communication, low-latency real-time collaboration, interactive cultural experiences, and WebGL-powered 3D environments to digitally represent India’s unity in motion.

In a nation of 28 states, 8 union territories, and 121 languages, EktaSahyog serves one singular purpose: **To Unite India.** It is not just a marketplace or a learning hub; it is a **National Integration Platform** that uses this advanced technology to dissolve the invisible borders that divide us.

## 🧠 Core Algorithms & Engineering Core

EktaSahyog is built on production-grade software engineering patterns:

1. **Route Code-Splitting Optimization (48.03% Bundle Reduction)**:
   - Implemented route-based dynamic imports in `src/App.jsx` using `React.lazy()` and `<Suspense fallback={<PageLoader />}>`.
   - Isolates heavy WebGL dependencies (`three`, `@react-three/drei`) and GIS mapping libraries (`leaflet`), reducing initial entry bundle from **2.54 MB to 1.32 MB** (**48.03% bundle size reduction**).

2. **Offset-Based Database Query Pagination (84.32% Latency Reduction)**:
   - Added optional `page` and `limit` query parameters to GET endpoints (`/stories`, `/projects`, `/marketplace`, `/culture`, `/hotspots`) using Mongoose `.skip((page-1)*limit).limit(limit)`.
   - Reduced query execution duration on 5,000 document datasets from **202.89 ms to 31.80 ms** (**84.32% latency reduction**).

3. **Multilingual Groq LLM & Security Pipeline**:
   - Ultra-fast AI inference engine running active models (`openai/gpt-oss-120b` for `Ekta Saathi` chatbot, `openai/gpt-oss-20b` for translation, toxicity detection, and sentiment scoring).
   - Wrapped in defense-in-depth security: `express-validator` payload sanitization, `express-rate-limit` rate-limiting (15 req/min on AI endpoints), locked CORS policy, and JWT tokens signed with explicit 7-day expiration (`expiresIn: '7d'`).

4. **Pure WebRTC Peer-to-Peer Video Calling (0% Server Relay Overhead)**:
   - Direct P2P audio/video media streams over `RTCPeerConnection` using Socket.IO for signaling.
   - Maps database user IDs to active socket connections (`userIdToSocket` Map) to avoid routing errors, eliminating third-party media SDK costs.

5. **Client-Side HTML5 Canvas Binarization & Tesseract.js OCR**:
   - Image pre-processing converts camera uploads to grayscale, boosts contrast (+20%), and applies adaptive binarization thresholding locally inside an HTML5 Canvas.
   - Executes Tesseract.js inside a client Web Worker thread, keeping raw ID photos on the user's device for complete data privacy.

6. **Socket.IO Real-Time Chat & 0.83ms RTT Event Bus**:
   - Auto-joins clients to regional channel rooms (`socket.join(user.location)`).
   - Measured round-trip time (RTT) averages **0.83 ms** across 100 WebSocket messages.

7. **Vitest + Supertest + `mongodb-memory-server` Isolated Testing**:
   - Automated test suite consisting of **12 unit and integration tests across 6 test files**.
   - Runs against an ephemeral in-memory MongoDB instance with **100% statement coverage on tested models and 4 core controllers** (auth, marketplace, projects, stories).

## 🚀 Comprehensive Feature Suite

### 1. Cultural Marketplace 🛍️
* **Fair Trade Artisan Hub**: Connects buyers directly with genuine weavers, potters, and craftsmen across India.
* **Dual Currency**: Items feature prices in Indian Rupees (INR) and Unity Points earned through platform engagement.
* **Tech Under the Hood**:
  * Regex-based search algorithm with category & regional filter controls.
  * Integrated Stripe payment intents (Test Mode) and webhook verification (`/webhooks`).

### 2. The Metaverse Bazaar (3D Experience) 🎆
* **Browser 3D Village**: Walk through a digital village as an avatar, experiencing sky lanterns and flower rains.
* **Interactive Stalls**: Click on virtual stalls to inspect products in 3D space.
* **Tech Under the Hood**:
  * Engine: **React Three Fiber (R3F)** & **Three.js**.
  * Particle Optimization: `InstancedMesh` rendering 150+ particles at 60 FPS.

### 3. Unity Projects & Social Stories 🤝
* **Collaborative Action**: Crowdfunding dashboard for cross-state relief initiatives (e.g. "Flood Relief for Assam").
* **Social Voices Feed**: Community story feed with likes, comments, and regional tags.
* **Tech Under the Hood**:
  * Stripe Webhook (`checkout.session.completed`) triggers atomic updates to project funding stats.

### 4. Cultural Arcade (Gamification) 🎮
* **Ancient Indian Games**:
  * **Moksha Patam** (Snakes & Ladders)
  * **Ganjifa** (Mughal Playing Cards)
  * **Pallanguzhi** (Traditional Mancala)
* **Tech Under the Hood**:
  * Custom React state grid boards and CSS 3D card flip animations (`preserve-3d`).

### 5. Universal Chatroom 💬
* **Multilingual AI Translation**: Automatically translates messages between regional users.
* **Tech Under the Hood**:
  * Socket.io room joining by location (`user.location` -> `socket.join('punjab')`).
  * Groq LLM pipeline for real-time translation, toxicity filtering, and sentiment scoring.

### 6. The Unity Council (AI Personas) 🏛️
* **Debate Chamber**: Interactive AI personas of Indian historical figures (**Sardar Patel**, **Tagore**, **Swami Vivekananda**, **Ambedkar**, **Sarojini Naidu**, etc.).
* **Tech Under the Hood**:
  * Custom System Prompts ("Soul Scripts") injected into Groq LLMs.
  * Native Web Speech API (`window.speechSynthesis`) integration.

### 7. Drishti-Milan (Peer-to-Peer Video Calling) 📹
* **1-on-1 Cultural Calls**: Video call portal featuring state-themed border colors and identity badges.
* **Tech Under the Hood**:
  * Pure WebRTC (`RTCPeerConnection`) with Socket.IO signaling. 0 third-party SDK dependencies.

### 8. Client-Side Browser OCR 👁️
* **Local ID Verification**: Scans ID documents locally without uploading sensitive raw images to the server.
* **Tech Under the Hood**:
  * `Tesseract.js` Web Worker WASM engine + HTML5 Canvas binarization thresholding.

## 🗂️ Database Architecture & 11 Mongoose Schemas

The application persistence layer consists of **11 Mongoose Schemas**:

1. **User**: Account profile, hashed password, role (`user`/`admin`), region GeoJSON (`2dsphere`), language, bio, skills, joined communities.
2. **Product**: Title, description, price (INR & points), artisan, region, category, sellerId.
3. **Order**: Purchaser userId, productId, productSnapshot, shippingAddress, status (`PENDING_ADDRESS`, `PROCESSING`, `SHIPPED`, `DELIVERED`), pointsPaid.
4. **Project**: Crowdfunding goal, raised amount, volunteer members list, location, organizer, status (`Active`/`Completed`).
5. **Story**: Author, content, preview, region, likes, likedBy, comments array.
6. **ChatMessage**: Channel/room, userId, text, translatedText, sentiment score & label.
7. **Resource**: Title, category, provider, region, verification badge.
8. **Hotspot**: Geo-tagged cultural locations with `2dsphere` coordinates.
9. **Culture**: Cultural encyclopedia cards per state (art forms, festivals, traditions).
10. **Community**: Interest groups with member arrays.
11. **GameScore**: User arcade game scores and playedAt timestamps.

## ⚡ Quick Start

All commands should be executed from the project root directory: `e:\EKTASAHYOG\EktaSahyog`.

### 1. Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start Express Backend Server (Terminal 1 - Port 5001)
node server/index.js

# 3. Start Vite Frontend Client (Terminal 2 - Port 5173)
npm run dev
```

### 2. Docker Container Deployment


## ⚠️ Limitations & Known Constraints

1. **Stripe Integration (Test Mode)**:
   - Configured with test API keys (`sk_test_`). Real production deployment requires live merchant keys and PCI-DSS compliance verification.
2. **WebRTC P2P Scope**:
   - Direct P2P architecture handles 1-on-1 calls with zero server cost. Scaling to 10+ participant group video calls requires an SFU media server (e.g. Mediasoup).
3. **Client OCR Image Quality**:
   - Tesseract.js extraction accuracy depends on ambient camera lighting and resolution. Includes fallback manual form editing if text scan fails.
4. **MongoDB Atlas Free Tier**:
   - Free tier clusters cap storage at 512 MB. Production scale requires dedicated tier MongoDB hosting.

## 📚 Lessons Learned

1. **WebRTC State & Signaling**:
   - Mapping database user IDs to active Socket.IO connection IDs (`userIdToSocket` Map) is essential to prevent missed call notifications across multiple browser tabs.
2. **React 3D Canvas Performance**:
   - `InstancedMesh` is over 10x faster than rendering individual `<mesh>` nodes inside dynamic Three.js scenes, preserving 60 FPS animation loops.
3. **Defense-in-Depth AI Security**:
   - Combining `express-validator` payload checks with `express-rate-limit` prevents API abuse and protects paid cloud LLM quotas.
4. **Route Code Splitting**:
   - Deferring heavy WebGL and GIS mapping chunks via `React.lazy()` cut initial bundle payload nearly in half (**48% reduction**).
